# Lunex TV: подключение разрешённых каталогов

Приложение использует HTTPS JSON endpoint, контролируемый владельцем или предоставленный официальным поставщиком контента. Не копируйте закрытые API, не обходите DRM, авторизацию или ограничения источников.

## Пример ответа

```json
{
  "items": [
    {
      "id": "movie-001",
      "title": "Пример фильма",
      "kind": "Фильм",
      "year": 2026,
      "description": "Описание",
      "poster": "https://example.org/poster.jpg",
      "url": "https://example.org/movie.m3u8",
      "episodes": []
    },
    {
      "id": "show-001",
      "title": "Пример сериала",
      "kind": "Сериал",
      "year": 2026,
      "description": "Описание сериала",
      "poster": "https://example.org/show.jpg",
      "url": "",
      "episodes": [
        {"season": 1, "episode": 1, "title": "Первая серия", "url": "https://example.org/s01e01.m3u8"}
      ]
    }
  ]
}
```

Все URL в примере фиктивные. Настоящий каталог должен иметь действительные HTTPS URL и права на показ.

## Текущие ограничения

- Поддерживаются только открытые HTTPS JSON каталоги без токенов и DRM.
- Прямые ссылки на MP4 и HLS передаются в Media3.
- История просмотра и избранное хранятся локально на устройстве.
- Постеры загружаются через Coil; источник должен разрешать загрузку изображений.
- Источники KinoPub и KinogoATV не интегрированы: для них нужны проверенные официальные интерфейсы, лицензии и способ авторизации.
- Удалённые каталоги не кэшируются; офлайн-режим не реализован.
- Для продакшена нужны безопасная проверка редиректов и адресов, обработка авторизации, pagination, rate limits, DRM при наличии прав, субтитры, выбор дорожек и тесты устройств.

## Тестирование

1. Откройте «Онлайн-каталог» и укажите собственный HTTPS JSON endpoint.
2. Нажмите «Загрузить каталог».
3. Проверьте постер, описание, сезон и эпизоды.
4. Откройте видео по прямой ссылке, проверьте перемотку, звук и восстановление позиции.
5. На Android TV проверьте D-pad, Back и системные кнопки Media3 PlayerView.
6. На смартфоне проверьте портретный и горизонтальный режим.
